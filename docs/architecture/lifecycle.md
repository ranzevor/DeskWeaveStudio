# 组件生命周期与本地授权

## 所有者与运行边界

Tauri Host 管理窗口和本地启动协调；每个工作空间的 Engine 是唯一数据写入者；每个登录会话的交互桌面只有一个 Desktop Agent。Bridge 和命令客户端连接同一 Engine，不建立第二套执行状态。

Engine 的功能能力、客户端授权和 Agent 输入租约分别判断。能够打开文档不表示 Agent 已就绪，能够调用某个方法也不表示有权访问该方法中的目标或资源。

| 对象 | 生命周期所有者 | 保持活动的条件 |
|---|---|---|
| 主窗口、浮条、选区和预览 | Tauri Host | 窗口及其本地命令仍活动 |
| Engine | 工作空间启动协调器 | 已认证客户端、活动运行、录制转存、观察会话、作业或未完成持久化 |
| Agent | 当前用户与交互桌面的启动协调器 | 受信客户端、租约、录制、资源传输或未完成输入清理 |
| Bridge | 启动它的本地服务会话 | stdio 连接或已明确保持的网络监听 |
| 视觉工作单元 | 创建作业的 Engine | 本次受限计算与取消收尾 |

稳定保存的历史记录和已结束作业不单独阻止退出。未确认效果必须先持久化；它在后续启动时继续阻止未经确认的输入，不依靠进程常驻保存。

## 发现、启动竞态与就绪

1. 启动器从本地选择记录取得目录定位信息，核对规范路径、目录实际对象和工作空间身份。路径只是定位信息，目录能力另行验证。
2. 先连接已登记端点并验证实际进程、创建时间、用户、系统会话、安装清单和实例 epoch。进程仍存活而握手未就绪时等待其启动结果，不立即创建副本。
3. 不存在可用实例时，争用工作空间启动锁；胜者启动 Engine，败者等待同一实例。规范路径的别名仍按实际目录和工作空间身份归并，不能形成两个写入者。
4. 新进程通过受保护的继承句柄取得一次性启动材料，命令行与发现记录不携带票据或模型凭据。进程身份不符合预期时不交付启动材料。
5. Engine 完成数据格式、数据库与对象索引检查后才公布可用端点。握手、认证和工作空间打开均成功后，客户端进入文档服务就绪状态。
6. 截图、录制或输入需要 Agent 时，再对当前交互桌面执行相同的连接优先与单实例竞争。Agent 完成平台检查、急停入口注册和必要清理核对后，才开放相应能力。
7. 两端记录协商后的协议、Schema 摘要、功能集合和容量。版本不兼容、启动超时、数据库占用和急停注册失败分别返回具体结果；编辑入口和输入入口按实际可用范围启用。

启动锁不授予数据库写入或桌面输入权限。清理过期发现记录前核对进程创建时间及 epoch，避免误处理复用的 PID。启动器只能终止自己创建、尚未被其他客户端接管的失败候选进程；既有实例继续提供其有效功能。

主窗口关闭或启动取消不影响另一窗口已连接的共享实例。启动失败可重新连接或显式重试；重试过程仍先核对原实例和未决请求。

## 连接层与客户端身份

连接状态依次为发现、身份核验、版本协商、认证、就绪和排空。未认证连接只处理连接层交换，不派发工作空间命令。连接层格式与业务消息边界见[本机协议](../interfaces/local-protocol.md)。

经认证的稳定客户端身份用于请求去重、作业归属和恢复；消息 session 只对应当前连接。稳定身份的恢复凭据由 Engine 与可信本地启动器通过受保护存储或句柄维护，客户端不能通过参数选择另一个身份。

重连必须重新核验当前进程和权限。恢复同一稳定身份只允许找回原请求和对象，不恢复已经撤销或到期的能力；身份恢复凭据校验失败时分配新客户端身份，按对象权限查询历史。

客户端跟踪 Engine epoch、Agent epoch、连接代次及文档代次。Engine 重启后丢弃旧订阅并重取快照；Agent 重启后丢弃旧目标、租约和资源句柄。已接收的修改先查 request.status，不能换请求身份自动重做。

## 本地能力的签发与消费

能力是登记方保存的有用途、对象与期限的记录；协议中的字符串仅为不透明引用。接收端核对引用在登记方的用途、对象、期限和当前状态。

| 能力 | 产生与登记 | 使用方与边界 | 消费与失效 |
|---|---|---|---|
| 目录打开能力 | Host 原生选择器确认实际目录，Engine 核验对象 | workspace.open；限定选定目录和工作空间 | bootstrap 兑换完成后结束；工作空间连接取得自己的有限权限 |
| 文件导入能力 | Host 选择具体文件并固定实际句柄、类型与长度 | asset.import、workspace.restore | 只读本次来源；替换、关闭、到期或撤权即失效 |
| 导出位置能力 | Host 确认目标目录或文件，固定父目录与允许写入范围 | workflow/template/observation 导出和备份 | 只写本次制品；禁止借链接或重解析点扩大目录 |
| 目标选择能力 | Host 选择窗口、单屏或全部显示屏，Agent 登记目标、用途及显示拓扑 | Engine 的 target.select 兑换 Agent 的 target.bind | 一次兑换；全部显示屏固定当时活动集合，拓扑变化后重新选择 |
| 目标令牌 | Agent 固定真实目标、进程创建时间、桌面、用途和期限 | capture、record、输入租约及持续观察 | 到期、目标消失、身份或 Agent epoch 改变即失效 |
| 本地确认能力 | Agent 的受信本地确认路径登记用户操作 | emergency.rearm | 绑定预期代次，一次使用；旧确认不解除新的锁定 |
| TLS 文件能力 | Host 确认对应证书与私钥来源和用途 | bridge.configure/start | 只用于当前本地监听配置，不转换为任意文件读取 |
| MCP 客户端令牌 | 本地管理入口经 bridge.token.issue 签发 | 指定工作空间、目标与权限范围内的 MCP 调用 | 到期或 bridge.token.revoke 后立即失效 |

一次性选择和确认记录使用不可预测的随机引用，绑定发起窗口、稳定客户端、工作空间、用途、当前进程 epoch 与期限；只允许指定接收者兑换。bootstrap 的目录选择先绑定实际目录对象，打开成功后才绑定正式工作空间身份。UI 到 Engine 的能力不能直接转作 Agent 输入许可，Agent 的采集资源也不能转作文件写入能力。

登记方验证能力时使用其记录和实际系统对象，不能只检查字符串前缀或客户端自述字段。引用必须已经登记，不能由调用者携带一段自述权限的 JSON 代替；一次性记录的消费与作业准入关联，重复请求返回原回执而不再次兑换。目录、来源文件或导出父目录在检查后被替换时重新核验实际句柄；不能沿用已经失效的路径结果。

未使用的窗口能力在窗口关闭时撤销。已明确创建的运行、作业或后台观察由 Engine 固定本次必要能力和期限；关闭编辑窗口不会把其中的任务参数改写成新的权限。临时读取句柄和界面订阅随视图关闭释放。

授权期限在可信选择或审批时确定，目标通过 expiresAt 返回。启动前检查期限与任务预算，任务不能因为计划更长而延长授权。lease.renew 只续输入租约，不延长目标授权；到期后停止新的输入或采集，按对象的停止规则收尾。需要再次操作时重新进行本地选择，创建新运行或观察会话。

撤权先提升对应控制代次、阻止新准入，再取消受影响输入和采集、关闭资源与订阅，最后记录清理结果。历史业务记录仍保留原效果。网络令牌撤销时是否同时停止其创建的运行，使用本地撤销操作明确给出的 stopOwnedRuns，不能由客户端重新决定。

## 窗口、客户端与后台工作

| 退出对象 | 默认处置 | 已明确选择后台时 |
|---|---|---|
| 编辑窗口 | 等待草稿持久化确认，释放该窗口的查询和图像资源 | 不改变其他窗口或已有 Engine 工作 |
| 交互运行的所属客户端 | 暂停并释放持有输入，保存运行状态 | run.start 的 detached=true 按固定授权和预算继续 |
| 独立观察的所属客户端 | observation.start 的 detached=false 会话进入停止过程 | detached=true 会话由 Engine 持有，目标和预算继续约束 |
| stdio MCP 客户端 | 关闭该协议会话和订阅，按所属对象退出策略收尾 | 已脱离客户端的运行或观察继续 |
| 网络监听管理窗口 | 在关闭流程中明确停止监听或保留后台服务 | 继续监听只维持原授权；不增加客户端或目标权限 |

关闭一个查看运行的窗口，不表示它就是运行的所属客户端。连接中断、所属客户端退出和取消一个工具等待分别处理。stdio EOF 与旧版协议会话明确结束传递对应客户端离开；Bridge 退出关闭其仍附属的客户端上下文。

新版 HTTP 根据工作空间和经认证的稳定客户端取得 Engine 委托上下文，逐请求重新验证令牌、授权和能力；clientInfo 与 HTTP 连接不决定所有者。上下文由 Bridge 的服务生命周期及原授权期限约束，普通请求完成、查询流取消和订阅断开不关闭该上下文。客户端停止已创建对象使用 run.stop、observation.stop 或 operation.cancel；服务停止、授权到期和撤销按各自规则收尾。runId、operationId 和 observation sessionId 是显式业务句柄，不能从一个请求流推定其他对象已经停止。

请求取消只传播到它仍拥有的在途操作；已返回业务句柄的运行和观察继续按 detached、对象控制和授权规则处理。现代 HTTP 没有协议级“退出会话”，界面也不把一个响应结束显示为整个客户端退出。

同一 Engine 的空闲计数包含客户端、活动/暂停运行、录制收尾、持续观察、排队/执行/取消中的作业、资源传输、持久化事务和排空中的 Bridge。观察不创建桌面输入运行，仍必须计入活动工作。网络服务明确保持监听时持有服务引用，即使当前没有 MCP 客户端也不判为空闲。

最后一个引用结束后进入空闲宽限，再次检查计数，提交必要状态、关闭资源和数据库，最后撤下端点。宽限期间的新连接取消退出；进入关闭状态后不再把新任务交给将退出的实例，而是等待其完成后重新发现。Agent 另按自己的连接、租约、录制、上传和输入清理计数退出。

## 正常关闭与更新顺序

1. 关闭发起方停止接收新的运行、录制、观察和作业；待保存草稿及既有作业的必要收尾仍可完成。
2. 按对象的所属关系和后台选择停止或转交工作：run.stop、observation.stop、operation.cancel、record.finish 使用各自当前身份和控制版本。
3. Agent 撤销后续输入，完成释放；Engine 收拢调用、作业、录制资源和状态事务。清理完成后发布终态。
4. 关闭该客户端的订阅和资源，等待持久化回执，再释放连接引用。共享 Engine 或 Agent 还有其他拥有者时继续运行。
5. 全组件更新先让 Bridge 停止新准入，协调全部工作空间和 Agent；确认输入释放、草稿保存及一致备份后才替换兼容组件。
6. 新组合启动后重新握手、检查数据和能力；旧目标、旧确认和旧租约不跨 Agent epoch 复用。打开窗口和恢复布局不自动恢复输入。

停止控制和紧急停止在排空期间保持可用。超时或清理失败保留实际对象与恢复入口，不强制把状态改为已停止，也不通过终止共享进程缩短关闭流程。

## 故障与恢复矩阵

| 故障 | 立即处置 | 恢复入口 |
|---|---|---|
| React/WebView 崩溃 | Host 使原窗口能力失效，通知所属客户端丢失；停止该窗口订阅和资源 | 重建窗口，读取已确认草稿与快照；不自动继续输入 |
| Host 或命令客户端退出 | Engine 按 run/observation 的 detached 与归属策略处理，丢弃旧连接材料 | 新进程重新认证，恢复原请求或读取已授权对象 |
| Engine 退出 | Agent 撤销该 Engine 租约并清理；其 Bridge 停止新业务准入 | 新 Engine 检查持久状态，活动运行标 interrupted，再核对输入收据 |
| Agent 退出或 epoch 改变 | Engine 阻止新输入；旧令牌、租约和资源失效 | 核对原生进程、收据及输入台账；不确定效果保留 uncertain，重新选择与本地确认后才允许新运行 |
| Bridge 退出或网络断开 | Bridge 退出处理所属上下文；网络断开按协议代际取消本次请求或结束等待，保留业务身份 | 重新认证，查询原请求及快照，不重发写入 |
| 图像或模型工作单元失败 | 原作业失败并收拢资源；不能用空结果替代错误 | 保留输入和配置，用户可以创建新作业 |
| 普通/提升 Agent 切换失败 | 保持输入闸门关闭，文档和普通功能继续 | UAC 重试或回到普通目标；不形成双发射端 |

录制的完整增量日志恢复为可修复分段，缺失事件不补造。模型响应、作业完成与数据库持久化分别确认；Engine 重启不把尚未保存的响应登记成成功记录。connection.configure 显式撤销旧凭据时，停止引用该凭据的会话，保留原配置版本及记录关联。

运行与输入控制见[执行设计](../design/execution.md)。启动竞争、最后窗口退出但观察仍活动、Bridge 退出、旧客户端恢复、目标到期及普通/提升切换纳入 Q10/Q15/Q19/Q23/Q28；验收时区分请求接收、进程状态、数据落盘及实际输入释放。

## 配置、令牌与更新信任的寿命

用户设置协调器是同一登录用户的单实例 Host 服务，持有用户配置版本与短时提交屏障；工作空间 Engine 对本层设置独立执行 CAS。读取快照记录用户基础版本，整批提交不能跨基础变更。等待 Agent 重启的设置只保存 pending，Agent 空闲排空并重新就绪后才确认应用版本，不在运行中偷偷切换。

TLS 选择能力在 bridge.configure 准入时一次消费。验证后的材料登记到监听专用的受保护绑定，后续启动只使用该绑定并重新核对证书期限及材料状态；已配置的监听继续使用其受保护绑定。读取与输出只提供证书状态和摘要，不能把绑定还原成通用文件访问。配置替换后，旧绑定保留至使用它的监听彻底停止，再清理未使用秘密。

MCP tokenId 与明文、验证材料分离。签发成功后保存验证材料及元数据，首次明文回复不写入普通请求回执；回复丢失使用非秘密 tokenId 撤销后重发，不以重放请求再次显示令牌。过期或撤销立即阻止新准入并关闭相关订阅和直接输入许可；列表分页快照不能延长令牌期限。历史元数据不恢复秘密。

更新协调器持有用户级唯一锁，先验证当前根链与吊销资料，再核对通道清单和制品，最后执行全组件排空。持久信任状态独立于工作空间和程序版本；组件回退不回退 root、吊销版本或每通道最高序号。人工降级确认绑定一份具体制品及当前信任状态，一次使用，十分钟到期，信任状态或目标变更即失效。停止下载不改变已接受的最高信任状态；原安装重试继续核对相同清单和实际字节。

## 平台会话

Agent 的发现与互斥键绑定真实登录会话、seat 和交互桌面域；同一桌面的 XWayland/Wayland 路径及不同安装版本共用拥有者。Windows 输入桌面切换、macOS 用户会话切换、X11 连接关闭、Wayland Portal 会话或 EI 设备失效均使相关目标与实时检查点失效。权限请求由可信本地入口触发，读取能力不弹系统对话框。具体身份、通信与清理见[跨平台设计](platforms.md)。
