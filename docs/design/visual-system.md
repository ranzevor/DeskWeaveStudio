# 视觉系统与界面规范

设计版本：0.1.0  
更新日期：2026-10-29

## 视觉方向

DeskWeaveStudio 采用专业创作工具的界面结构：浅色窗口外壳承担导航、参数和记录阅读，浅色点阵画布承载流程关系，紫色标识当前操作与选中对象。视觉密度适合长时间制作和调试，操作入口与参数保持可见。

[核心页面高清效果图](high-fidelity.md) · [全部界面](prototypes.md) · [交互画册](../prototypes/index.html)

## 色彩与层级

| 用途 | 色值 | 使用位置 |
|---|---|---|
| 页面底色 | #F6F8FB | 资产、观察、运行与设置的内容区 |
| 一级表面 | #FFFFFF | 侧栏、参数面板、表格和弹窗 |
| 次级表面 | #F2F3F8 | 控件组、辅助区域和未激活标签 |
| 主要文字 | #20243A | 标题、对象名称和结果 |
| 次级文字 | #697087 | 字段说明、时间及单位 |
| 分隔线 | #E5E7EF | 表格、面板与窗口区域 |
| 主操作 | #5657E9 | 运行、保存、选中项和可见焦点 |
| 主色底 | #EEEDFF | 当前导航、选中标签与能力标记 |
| 成功 | #24775F / #E9F6EF | 已完成、已保存和校验成功 |
| 等待与需处理 | #936413 / #FFF6E3 | 暂停、冲突和等待确认 |
| 失败 | #BB4354 / #FFF0F2 | 具体错误、无法保存和急停 |
| 技术结构表面 | #F6F8FC | 消息预览与源码 |
| 深色辅助文字 | #A3ADC3 | 暗色主题的字段和说明 |

流程节点按时间、视觉、输入、子流程和结果区分标识色；选中状态同时使用边框、图标及名称。运行、保存和模型请求的状态分别表达，色彩不替代状态文字。

## 排版与尺寸

| 对象 | 规格 |
|---|---|
| 字体 | Segoe UI Variable Text，回退到 Segoe UI、Microsoft YaHei UI |
| 源码与时间 | Cascadia Code、Consolas；中文使用系统字体回退 |
| 页面标题 | 25px，字重 650 |
| 面板标题 | 13–14px，字重 600 左右 |
| 表单与列表 | 12–14px，按信息层级分配字重 |
| 辅助信息 | 11–12px；关键操作不依赖缩略文字 |
| 顶部区域 | 标题栏 34px，工作栏 60px |
| 主导航 | 66px；图标与文字同时展示 |
| 编辑侧栏 | 流程与资源 220px，属性区约 300px |
| 状态栏 | 26px，显示工作空间、保存与急停入口 |
| 基础间距 | 4 / 8 / 12 / 16 / 20 / 24 / 32px |
| 圆角 | 按钮 7px、控件 7–9px、面板 12px、弹窗 15px |

标准工作区为 1440 × 900 CSS 像素。800 × 600 的窄窗口采用抽屉、可折叠侧栏及等价步骤入口。高清效果图使用 2× 浏览器采样，保留文字和控件的实际布局。

## 页面构成

### 流程工作台

左侧按工作空间、流程、固定依赖和制作工具分层。中部共用流程、步骤和源码三个视图；浅色画布保留入口、命名出口、连接方向、选中节点、缩放与微型视图。右侧按常规参数、资源、执行条件和产出分组，底部展示问题与运行信息。

### 模板生产与资产

模板生产按来源、检测、筛选与命名、保存批次组织。候选图保留原始尺寸、评分、算法来源与选集状态。资产卡片区分图像模板和输入轨迹，显示版本、引用和必要的尺寸或时长。

### 观察中心

概览以记录列表为主，结合当前会话、周期、最近检查和状态分布。历史查询始终显示时区与时间范围；详情使用对应记录的截图、结果、耗时和用量。无变化与忙碌跳过采用各自的原因和附件状态。

### 运行监控

调用树、执行时间线和变量详情分区排列。当前步骤、固定版本、主动耗时和输入清理状态位于顶部摘要中。失败、暂停、停止和急停的操作保留明确层级。

### 连接与 MCP

模型参数与消息结构分区；JSON 预览采用浅色背景、行号和语法配色。MCP 将传输、监听、令牌和能力目录分开，工具与预设任务的表单来自机器可读定义。

## 组件状态

| 组件 | 必须表达的状态 |
|---|---|
| 按钮 | 普通、悬停、焦点、按下、禁用和进行中 |
| 字段 | 已填、空值、无效、只读及需要修正的具体原因 |
| 表格与列表 | 当前选中、筛选结果、空结果和必要的分页 |
| 作业 | 进行中、已取消、失败和完成结果 |
| 保存与导出 | 正式保存、未保存、独立恢复文件及输出范围 |
| 弹窗与抽屉 | 入口上下文、主操作、取消、关闭返回及键盘焦点 |
| 深色主题 | 背景、文字、边框、焦点、状态色和弹层的对应颜色 |

按钮反馈不依赖装饰动效。字段错误位于对应控件附近；长表单保留独立滚动区及可达的主要操作。焦点、输入法、快捷键与返回行为见[交互设计](experience.md)。

原生控件和滚动条按所在窗口的明暗主题设置 color-scheme。画册导航、页面、弹窗、文本框、源码和嵌套列表共用滚动条变量；操作系统深色偏好不改变浅色窗口的原生配色。强制颜色模式使用系统滚动条颜色和宽度。
