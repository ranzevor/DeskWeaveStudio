# 产品需求

## 产品目标

DeskWeaveStudio 让用户把一段桌面操作制作成可检查、可修改、可重复执行的流程。用户能够找到失败发生的位置，保留已有版本，并在需要时立即接管桌面。

## 使用角色

| 角色 | 主要任务 | 操作范围 |
|---|---|---|
| 流程作者 | 录制、编排、验证和保存流程 | 已打开工作空间的草稿与资产 |
| 任务操作者 | 选择目标、填写参数、启动与停止 | 被授予的流程版本与桌面会话 |
| 集成开发者 | 经 MCP 创建运行、查询结果 | 客户端连接绑定的工作空间和目标能力 |
| 维护者 | 修复、评审、构建和发行 | 仓库和发行渠道的实际权限 |

作者和操作者可以是同一个人。MCP 连接的建立不自动授予桌面输入或外部模型调用权限。

## 首期完整使用场景

1. 创建工作空间，选择全部显示屏，连续录制跨屏操作；在时间轴裁剪、核对屏幕布局后保存版本。
2. 截图框选按钮，测试定位，把匹配与点击加入流程；运行后检查预期窗口状态。
3. 用参数运行同一流程，在断点读取变量，修正草稿后启动新版本。
4. 在子流程运行中触发停止或急停，确认所有输入释放与后台作业收拢。
5. 导出含资源的任务包，在另一工作空间导入、绑定目标并运行。
6. 通过 MCP 创建运行；连接中断后查看明确的运行与效果状态。

7. 批量提取模板，检查命名和冲突，保存并导出一个完整资产批次。
8. 配置持续观察，筛选最近与跨日记录，查看跳过原因并导出所选截图与结果。
9. 用有界条件循环和运行共享变量组织重试；从指定节点校验前置数据后创建新运行。
10. 配置网络 MCP 客户端，发现工具、资源和预设任务，撤销令牌后验证旧会话失效。

## 非功能要求

| 编号 | 要求 |
|---|---|
| DW-N01 | 本地编辑、录制和模板匹配可以离线使用；网络模型单独配置 |
| DW-N02 | 工作空间对象、凭据和诊断内容按用途存储与导出 |
| DW-N03 | 在 1,000 节点、10 万轨迹事件和持续事件流下有明确容量行为 |
| DW-N04 | 从锁文件和固定工具链构建可安装制品 |
| DW-N05 | 公共格式和接口按版本演进，破坏性变更有迁移与恢复路径 |
| DW-N06 | 性能目标通过安装版测量，口径见验证设计 |

首个稳定版不包含远程桌面服务、云账户、多人实时编辑或任意可执行插件。相关扩展按独立提案确定授权、数据和兼容契约。
