# 屏幕、轨迹与视觉设计

## 目标和帧

目标槽由用户绑定到实际窗口或显示区域。Agent 返回不透明 targetToken，绑定进程创建时间、会话、桌面和授权范围；客户端不直接传 HWND 作为授权对象。

截图帧包含 frameId、捕获时间、目标版本、物理桌面原点、像素尺寸、裁剪区域和显示拓扑代次。保存模板时保留源帧、裁剪矩形和内容摘要。

## 坐标契约

界面坐标、窗口逻辑坐标、图像像素、全局物理坐标和带显示身份的屏内像素分别标记。跨平台逐屏变换以实际后端元数据建立，不能将 Retina 点、X11 根坐标或 Wayland region 直接当作采集像素。框选先消除图像容器内留白、滚动与缩放，再用帧变换转换为物理位置。跨屏图像不假设统一 DPI，原始相对鼠标量不进行 DPI 换算。

矩形采用左闭右开边界；负桌面坐标合法，宽高必须为正；仅在最终像素或系统调用边界取整。拓扑、目标位置或尺寸改变时，旧定位结果不能直接点击。

采集遇到最小化、遮挡、权限拒绝或空白帧时返回具体采集状态。不得在目标窗口失效后回退为整屏上传。框选覆盖层和录制浮条不能进入最终模板。

## 录制

录制默认覆盖全部活动显示屏，单屏与窗口作为可选范围。跨屏坐标、录制状态及回放映射见[全显示屏录制](recording.md)。

Agent 使用单调时钟保存事件，保留按键、鼠标按钮、滚轮、原始相对移动及事件自身携带的物理位置，不使用后续光标查询结果回填历史事件。暂停时间从轨迹时间中扣除；完整事件先进入增量日志，UI 接收有限频率预览。

[轨迹 Schema](../../contracts/trajectory.schema.json)约束事件字段。额外语义检查包括时间非递减、按钮/按键状态配对、事件总量和坐标空间一致性。

裁剪跨越按下区间时，以可撤销修改显示所需的起止释放调整。压缩预览可以抽样，回放数据保留全部中间绝对位置和原始相对量，包含停顿、转折、交叉和各笔画的按住区间；不能只保持累计位移。采集、连续绘制和原生发送见[连续指针与笔画](pointer-motion.md)。中断录制恢复为有效分段草稿，缺失事件不补造。

## 按键与回放

key 使用已登记的物理键符号：字母 a～z、数字 0～9、功能键 f1～f24、方向与编辑键，以及带左右侧的 ctrl_l/ctrl_r、alt_l/alt_r、shift_l/shift_r、meta_l/meta_r。平台能力目录提供完整键表和扫描码映射；未知键在发送前拒绝，字符文本通过 keyboard.text 表达。

coordinateMode=physical 使用桌面物理位置，display 使用 1.1 的屏内像素，relative 使用相对增量，event 结合来源坐标空间与每条事件种类解释。pointer.delta 表达发送的相对增量，录制来源和目标后端分别记录能力；目标应用实际接收相对输入需经原生用例确认，不能由回放接口接受推定。

文本操作固定 Unicode 内容和发送间隔，不转换成依赖键盘布局的字母按键序列。录制默认保留物理键；文本事件由显式编辑或受支持的文本源产生，不从物理键猜测 Unicode。回放以轨迹开始的单调时钟加 atUs 调度，首事件的等待不能丢失，暂停移除的时段不在继续后再次计入。记录暂停期间的输入不加入轨迹；恢复时重新建立物理状态基线，缺失配对在时间轴中作为明确编辑处理。

## 匹配

vision.match 读取固定图像资源，在目标或指定 ROI 中计算候选位置，结果包含帧、矩形、匹配分数、尺度、耗时和唯一性。

阈值是算法分数阈值，不表示业务成功概率。多个候选必须使用明确选择策略或返回歧义；点击取得输入许可后重新核对目标和定位。缓存键至少包含图像摘要、预处理版本、尺度与算法参数。

首期采用 CPU 模板匹配，提供透明通道、区域、多尺度和取消能力。OCR、UIA 定位器和 GPU 后端通过同一定位结果契约扩展。

## 模型观察

vision.observe 需要明确的连接、模型、目标区域、提示词、超时和输出格式。Engine 读取凭据并发起请求，WebView 不持有密钥。

自动观察每次最多一个在途请求；上次未结束时跳过本次触发，不无限排队。取消后，迟到响应保留原作业关联，不覆盖新观察或复活已取消状态。

响应按声明的结构校验。文本和图片内容不能修改工具授权、文件范围或原生代理能力；模型结果用于展示或显式流程分支。将来生成流程时，输出应先形成可审阅草稿，再经过同一保存与运行路径。

## 资源寿命

即时帧、缩略图和匹配叠层为可回收缓存；模板、轨迹与被运行引用的附件是持久对象。资源读取按工作空间、用途与有效期授权，大图分块传输；前端关闭视图后释放位图、对象 URL 和订阅。

## 制作与观察入口

批量候选检测、命名、冲突与资产批次见[模板生产](templates.md)；持续会话、变化检测与记录查询见[观察中心](observations.md)；模型消息、采样参数和结构化结果见[模型连接](model-connections.md)。

vision.match、vision.observe 和 capture.create 接收可选 roi。矩形采用目标实际采集帧中的 targetPixels，相对帧左上角计量；范围必须完整位于目标内，拒绝越界，不自动改成整屏。vision.match 的 scales 为 0.1～4.0 的明确比例列表，最多 128 项，不重复；省略时使用 0.5～1.5、间隔 0.05 的初始列表。运行前固定有效列表，缓存和结果记录实际使用的参数。

定位令牌绑定目标代次、模板摘要、ROI 和尺度集合；取得输入许可后用相同配置重新核对。参数修改后旧定位不能直接用于点击。

## 精确裁剪与多问题修复

裁剪范围为源轨迹时间中的 [fromUs, untilUs)，保留 atUs >= fromUs 且 atUs < untilUs 的事件；untilUs 必须大于 fromUs，且不超过源时长。输出事件时间减去 fromUs，编辑会话中的输出时长为 untilUs-fromUs；Trajectory 保持来源 formatVersion、coordinateMode 和未改动的事件字段，包括 1.1 的 displayId、小数位置及 inputProfile；写入已有 source 坐标上下文，裁剪起点保留显示身份；首次事件仍保留相对裁剪起点的等待。预览分别显示源时间和输出时间，同一时间的事件保持源顺序。

左边界之前已按下、选段内释放的按键或按钮构成缺失按下问题；选段内按下、右边界仍未释放构成缺失释放问题。用户逐项选择“在起点补按下／在终点前补释放”或“移除该持有区间”；默认不自动修复。补事件标记为编辑生成；起点事件位于 0，释放事件位于 durationUs-1 微秒，顺序按原配对关系稳定排列。极短片段无法容纳合法配对时禁止该修复方案。移除区间同时移除对应的按钮或按键事件，不删除无关指针位移。

多问题列表支持全选及对兼容项批量选择策略，不支持策略的项保留未处理状态并可定位原事件。所有问题解决、事件时序及配对检查通过后才能应用。预览显示保留／移除／补充事件数和暂停区间处理；不发送输入。应用生成一次可撤销编辑，撤销恢复源事件、时长和选段。源版本改变、选段改变或策略改变后，旧预览失效并须重新计算。

## 键盘截图选区

选区使用当前目标帧内的 x、y、width、height，单位为图像像素。方向键移动 1px，Shift+方向键移动 10px；Alt+方向键改变右或下边界 1px，Alt+Shift+方向键改变 10px。数值表单提供等价路径，最小宽高为 1px；矩形必须完整位于帧内。边界操作不越界，保留当前选区并提示达到哪条边界；数值越界标记具体字段，不静默裁成另一区域。

覆盖层打开后焦点落在带名称的选区，Tab 可进入 x/y/宽/高和确认、取消按钮。按 Enter 确认有效选区，Esc 取消并返回仍存在的原触发控件；文本输入中的 Enter 仅提交当前数值，不提前完成截图。焦点离开选区后方向键不再移动矩形。读屏以合并后的文字状态报告位置、尺寸和边界，每 300ms 最多一次；确认、取消与错误立即报告。捕获帧或显示拓扑失效时禁用确认并提供重新采集入口。

## 编辑结果保存

手工模板与时间轴的保存使用 asset.edit.prepare/commit/discard，见[制作事务](authoring-transactions.md)。像素和轨迹先验证、再发布不可变版本；失败保留编辑，正式资产绑定仅在原作业成功后更新。

## 匹配候选与语言查询

匹配作业的最终结果返回 candidateCount、candidatesQuery、selectedIndex 与 selected。完整候选按最低分数和尺度分页查询，selectedIndex 使用来源集合中的固定序号。已选定位独立于当前查询页。ocr.status 返回本次请求语言的可用状态、缺失语言、installedLanguageCount 和 installedLanguagesQuery；已安装语言目录按名称分页查询。字段与游标约束见[分页查询](../interfaces/pagination.md)。
