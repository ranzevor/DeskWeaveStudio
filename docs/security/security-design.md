# 安全与权限设计

## 保护对象

工作空间文档、截图与业务输入、模型凭据、桌面控制权、发行签名密钥分别授权。每项能力绑定操作、对象、用途和期限，连接建立不自动授予写入或输入。

## 信任边界

| 边界 | 检查 |
|---|---|
| WebView → Tauri | 可信窗口、帧和文档身份，允许命令，资源与代次 |
| Tauri/MCP → Engine | 实际客户端、工作空间、对象归属和方法权限 |
| Engine → Agent | 租约、目标、输入段、epoch、代次与有效期 |
| 普通 Agent → 提升实例 | UAC、签名制品、互斥切换与最小协议 |
| 导入包 → 工作空间 | 路径、大小、摘要、Schema、引用和内容类型 |
| 视觉模型 → 流程 | 结构校验、受限呈现，不增加工具权限 |
| PR → CI/发行 | 不可信输入、只读令牌、隔离制品与签名环境 |

## 能力与连接

workspace.manage、workflow.read/write、asset.read/write、run.read/execute/control、capture.read、desktop.input、desktop.stop、vision.local/remote、connection.write、settings.read/write、observation.read/control 分开授予。授权由可信客户端操作产生，不接受消息中的角色覆盖。

Windows 本机管道使用登录 SID 的显式 DACL 并拒绝远程访问；macOS/Linux 使用私有 Unix socket、原生对端身份与受保护连接票据。各平台核对实际进程、用户会话和安装身份。连接票据通过受保护通道传递，不置于命令行或可读发现文件。认证后仍逐命令校验对象和用途。

撤权增加控制代次，旧请求和句柄失效。后台作业、缓存或重连不能复活授权；已发生的外部效果继续保留原记录。

## 原生桥与提升

Tauri capabilities 按主窗口、浮条、选区和预览分配，核对叠加后的权限。自定义命令同时检查参数和授权。

发布版只加载内置前端，限制导航、子帧、子窗口、脚本和连接来源。Monaco worker 与本地图像协议使用窄范围 CSP；不暴露通用文件系统、shell 或反射对象。异步回复核对窗口和文档代次。

提升实例只处理限定目标的输入与采集协议，不运行工作流、脚本、外部程序或任意模块，不提供任意文件写入接口。拒绝 UAC 后保持文档和普通功能可用。

## 路径、内容与秘密

目录能力由原生选择器生成，服务端绑定实际对象。路径检查覆盖规范化、大小写、链接、重解析点、设备路径和创建后替换；字符串前缀检查不能单独保证文件边界。

导入附件不执行，文本使用纯文本或受限 Markdown，禁用原始 HTML。解压在独立 staging 完成，禁止覆盖任意目录。

凭据分别由 Windows 凭据设施、macOS Keychain 或 Linux Secret Service 保存，并由 Engine 按用途读取，UI 只写入新密钥并获取配置状态。密钥不进入流程、快照、导出、日志、错误和命令行。环境变量回退须由用户选择连接配置，任务不能指定任意环境项。

用户可以配置本地推理服务；流程仅引用已配置连接，重定向不能越过授权主机。网络请求校验证书，不通过关闭 TLS 检查恢复连接。目标失效不回退成全屏采集或上传。

可选遥测默认关闭；模型、更新和遥测分别控制。升级和配置迁移保持用户选择。

## 威胁与验证

| 威胁 | 预期处理 |
|---|---|
| 假管道占名、伪造 session、同用户无关客户端 | 双向核验失败，无秘密或输入发送 |
| 旧 Agent 或过期租约提交 | 原生提交点拒绝旧代次 |
| 迟到结果写入另一文档 | 身份和编辑代次检查拒绝 |
| 包路径穿越、压缩炸弹、恶意表达式 | 校验拒绝，正式对象不变 |
| 截图或模型文本要求读取秘密 | 内容不能进入权限控制 |
| 外部 PR 读取发行密钥 | PR 环境没有该秘密和发布能力 |
| 签后制品被替换 | 实际消费字节核签名和摘要，失败不安装 |

普通用户态应用无法在管理员或内核已被控制时强制其隔离；正常会话内的对象检查和最小能力仍须执行。

## 网络接入与视觉作业

网络监听配置与令牌管理仅限可信本地设置入口，不向 MCP 工具开放自我授予权限。每次请求检查 Bearer 令牌、工作空间、目标范围、期限与撤销代次；新版逐请求元数据与旧版握手分别校验，协议代际不改变对象权限；订阅逐次核对授权，旧 HTTP+SSE 的消息提交与事件连接使用同一授权上下文。令牌不放在 URL 中。

网络接入校验 Host、Origin 和 TLS；非回环监听必须先具备有效 TLS 配置，禁止通配来源。令牌撤销立即关闭相关订阅和直接输入许可；运行是否停止按本地确认的撤销选项执行，停止过程保留可查询状态。

提取的候选集、命名预览和观察记录均检查工作空间归属。模型配置模板按 JSON 数据处理，拒绝未知占位符及改变目标或凭据的扩展参数。持续观察逐次验证采集授权，连接建立或历史查询权限不授予新的截图范围。

## 录制范围

录制能力按窗口、单屏或固定的全部活动显示区域授予，独立于像素采集和桌面输入用途。MCP 不取得本地录制方法。新接入显示区域不进入旧录制，拓扑变化后须重新选择；跨屏回放的目标显示集合在输入前核对。具体规则见[全显示屏录制](../design/recording.md)。

## 平台授权

macOS 输入监听、事件发送和屏幕录制分别检测；Wayland 的屏幕共享、控制输入及普通桌面录制分别建立能力。系统拒绝、撤销或会话关闭立即使相应目标失效。权限读取不触发申请，外部 MCP 调用不能自动完成本地系统确认。

Unix socket 的文件权限和对端 UID 不单独构成应用身份；跨平台仍执行启动票据、挑战和逐对象授权。密钥环不可用不回退为明文，Portal restore token 不进入流程或导出包。完整规则见[跨平台架构](../architecture/platforms.md)。
