# 模板生产与批量资产

## 制作入口

资产库提供“制作单个模板”和“批量提取”。批量提取的来源为一次已授权采集帧，或工作空间内固定版本的图像资产。选择截图区域后使用目标像素坐标；源图、区域、选项和内容摘要在开始时固定。已有图像不触发新的屏幕采集。

操作路径为：选择来源 → 设置提取条件 → 查看候选 → 筛选与命名 → 确认保存 → 查看资产批次。运行和失败状态保留源图与有效设置，取消后可以重新开始。

## 候选检测

[视觉对象契约](../../contracts/vision.schema.json)中的 extractionOptions 定义实际参数。

| 参数 | 执行含义 |
|---|---|
| algorithms | 轮廓、颜色和角点的权重，至少一项大于零；结果评分按本次启用权重归一化 |
| minArea / maxArea | 候选像素面积范围，最小值不能大于最大值 |
| minAspectRatio / maxAspectRatio | 宽高比范围，使用实际裁剪后的矩形 |
| minConfidence | 融合评分的最低值 |
| deduplication | 空间重叠与图像相似度联合去重，不能仅因图像相似而合并不同位置 |
| filterText | 排除独立正文块；带文字按钮保留控件轮廓 |
| maxCandidates | 本次候选上限，达到上限时报告截断数量 |
| timeoutMs | 整个检测作业预算，取消和超时均收拢计算单元 |

检测工作单元共享本次灰度、边缘和预处理缓存。每个候选提供矩形、像素尺寸、算法来源、评分、缩略资源和 SHA-256；合并保留来源集合。排序使用评分、位置及候选身份作为稳定的次序。空结果是有效完成状态，算法异常与超时分别报告。

extractionResult.source 保存已固定的采集帧或图像资产版本，sourceSha256 保存源图像内容摘要，truncatedCount 保存因候选上限截去的数量；sourceFrameId 仅在采集帧来源时填写。候选通过同一来源和矩形追踪到实际像素。

候选集在工作空间暂存，默认保留 30 分钟。正在命名、保存或被打开的批次固定引用；过期后需要重新提取。缩略图不能替代导出原图。

## 筛选与命名

预览支持评分筛选、放大、全选、反选和取消所选。删除候选只修改本次选集，源图和已登记资产不变；键盘提供相同操作。

命名策略支持 OCR 后规则命名、仅规则命名和手工名称。OCR 使用已安装的本机引擎与语言包；启用前通过 ocr.status 检查。缺少引擎或语言时按所选策略转为规则命名，或停止命名并保留候选。

规则名由用户前缀、位置、元素类别和顺序构成。OCR 文本只作为建议名称，不执行其中的内容。每项记录实际命名来源；无 OCR 结果、图像不可读和引擎失败保留各自原因。批量预览允许逐项覆盖名称。

显示名称以 Unicode NFC 归一化后检查长度和重名。文件导出另外检查分隔符、控制字符、设备名和尾随点空格。重名可选择追加后缀或返回冲突；禁止静默覆盖资产。修改选集、候选版本、命名策略或已有名称占用后，旧命名预览失效。

## 保存与导出

template.names 返回绑定候选版本和选集的 proposalId、proposalHash、itemCount、conflictCount、itemsQuery 与可提交状态。命名项按名称、来源和冲突条件执行 query.read 分页；canCommit 根据完整选集计算。存在名称冲突时禁止提交。template.commit 只接收有效预览，不接受客户端提交的任意图片路径。

保存先验证全部裁剪、编码、名称和摘要，再写入对象存储，最后用一个数据库事务登记整个批次及引用。数据库提交前发生失败，不登记半份正式资产。暂存中的有效内容和命名预览可用于重试；提交后的回执丢失使用原请求查询，不能重复创建批次。

成功结果返回 batchId、assetCount、assetsQuery 与清单资源。每个候选对应的资产版本通过 query.read 按名称或候选分页查询。批量导出仅处理已提交资产，生成图像和清单，清单包含来源、矩形、评分、实际名称、命名来源、长度与摘要。导出中断不修改资产，未完成目录提供明确失败结果，完成清单在全部写入后生成。

## 接口与交互

| 方法 | 用途 |
|---|---|
| template.extract | 固定来源和选项，创建可取消提取作业 |
| template.candidates | 按候选版本分页读取和筛选 |
| template.names | 生成完整命名状态与命名项查询入口 |
| query.read | 按条件分页查询命名项、批次资产及已安装语言 |
| template.commit | 提交一个有效命名预览 |
| template.export | 导出已提交模板及清单 |
| template.discard | 释放暂存候选集 |
| ocr.status | 检查引擎及所选语言可用性 |

进度显示检测、融合、命名、编码和提交阶段。候选、命名冲突、OCR 不可用、空结果、取消、计算失败与保存失败均有独立状态及返回路径。具体画板见[全界面原型](prototypes.md)，验收见 Q21/Q22。
