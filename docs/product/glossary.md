# 术语与状态

## 对象

| 名称 | 含义 |
|---|---|
| 工作空间 | 集中保存流程、草稿、素材和运行记录的地方 |
| 流程 | 按步骤组织的桌面操作，可设置参数、条件和子流程 |
| 版本 | 某次保存的固定内容，用于查看、比较和再次运行 |
| 草稿 | 当前正在编辑的内容；源码尚不完整时也保留原文 |
| 运行 | 使用所选流程版本、参数和目标执行的一次任务 |
| 节点 | 流程中的一个动作或控制步骤 |
| 调用 | 主流程或子流程的一次执行，可查看当前步骤与变量 |
| 资产 | 可在流程中复用的图像模板、录制轨迹、截图和数据 |
| 目标 | 本次操作选定的窗口、显示屏或区域 |
| 输入段 | 一次连续操作，例如拖拽、组合按键或轨迹回放 |
| 桌面控制权 | 运行当前使用桌面的资格，用于避免不同任务同时操作 |
| 暂停位置 | 暂停时停下的步骤或轨迹位置，以及继续时需要恢复的输入 |
| 继续确认 | 继续运行前，对目标、指针位置和按键状态的确认 |
| 断点配置 | 在指定节点执行前暂停的设置；新运行使用启动时选择的配置 |
| 导入映射 | 任务包中的流程和素材在当前工作空间中的保存位置与复用关系 |
| 设置覆盖 | 对当前用户或工作空间单独设置的值；恢复继承后采用上层设置 |
| 作业 | 需要一段时间完成的操作，例如导入、模板提取或导出 |
| 观察检查 | 按设定周期检查目标的一次操作 |
| 查询结果 | 按当前筛选条件取得的一组记录，翻页时保持相同读取时点 |
| 目标结果 | 目标应用中实际发生的变化，例如已填写文字或出现下载文件 |

## 编辑与保存

草稿可以处于未修改、已修改、保存中、保存失败或版本冲突状态。保存失败时保留编辑内容；发生版本冲突时先比较新版本，再决定如何保存。

源码不完整时，源码页保留原文，画布和步骤页继续显示最后有效内容。保存正式版本前需要修正问题。

## 运行与输入

运行可以处于排队、准备、运行中、暂停中、已暂停、停止中、已完成、失败、已取消或已中断状态。结束的运行保留记录；再次执行会创建新运行。

“输入已发送”表示按键或鼠标操作已经提交；“结果已确认”表示流程中配置的结果检查已经通过。连接中断且操作结果不明时，先查看目标应用，再决定是否重新运行。

暂停和停止会释放本次运行按住的按键与鼠标按钮。释放未确认时，按界面指引接管桌面并核对输入状态。

## 作业、观察与查询

作业开始后可查看进度、查询结果或取消。“已接收”后的操作进入排队或处理中，完成结果显示在对应作业中。

观察记录分别显示检查结果与保存状态。忙碌跳过表示这次没有采集；无变化跳过表示已与上次对比图像比较。选择后台观察后，关闭工作台仍可继续；目标或连接授权失效时停止观察。

分页查询的默认有效期为五分钟。到期后保留筛选条件并重新查询；变量查看等页面按各自显示的期限更新。

## 时间与位置

运行记录按用户时区显示。轨迹编辑使用毫秒或微秒；页面标明当前单位。不同显示屏的像素尺寸和排列分别显示，用于选择录制范围及回放位置。

对象通过流程名、节点名、目标名称、版本和发生时间定位。接口字段、内部身份和状态编码见[协议对象与状态](../interfaces/objects-and-states.md)。
