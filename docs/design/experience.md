# 工作台与交互设计

## 页面结构

主导航为“工作空间、资产、观察、运行、设置”。观察入口打开会话中心，资产入口提供批量模板制作。任务标签显示流程名、保存状态与当前版本。运行控件始终展示所用版本与目标。

```text
工作空间 / 流程名称       已保存版本      目标      录制  运行  暂停  停止
┌────────────┬─────────────────────────────┬──────────────────┐
│ 流程与动作 │ 流程 / 步骤 / 源码         │ 属性与目标       │
│            │                             │                  │
│ 搜索、收藏 │ 画布、结构列表或源码       │ 参数、变量、出口 │
│ 模板、模块 │                             │ 定位测试与错误   │
├────────────┴─────────────────────────────┴──────────────────┤
│ 运行树 / 时间线 / 观察 / 问题                               │
└────────────────────────────────────────────────────────────┘
```

## 编辑行为

- 动作库按输入、定位、逻辑、流程和数据分类；支持搜索、收藏及“添加下一步”。
- 节点只显示标题、目标与关键摘要。完整参数在属性面板，数组与轨迹使用专用编辑器。
- 单位显示在字段旁；数值、布尔、枚举、资源、变量引用分别使用对应控件。
- 连线带出口名称；键盘菜单提供相同连接操作。删除节点时同时处理入边、出口和资源引用。
- 源码与图共享草稿版本；语法错误定位到原文，语义错误可定位到节点或参数。
- 自动布局、折叠和缩放不修改流程控制关系。

## 录制与目标

开始前确认目标、显示范围和热键。浮条显示时长、事件数、暂停和结束，不抢占目标焦点。录制与回放互斥；冲突时提供停止当前操作的入口。

目标失效时保留选择信息，要求重新绑定。截图框选显示实际捕获帧；取消框选返回触发控件，模板和草稿不丢失。只读匹配测试与发送测试输入是两种明确操作。

## 运行与恢复

运行树展示调用层级、当前节点、状态、耗时与已执行数量。条件和重复流程不显示无法确定总量的百分比。失败详情包含动作、目标、具体原因与必要附件。

暂停请求先显示“正在暂停”；Agent 释放输入且 Engine 到达安全点后显示“已暂停”。断线显示连接状态并保留草稿；重连后按服务快照恢复运行投影。

关闭窗口时分别处理草稿和运行。用户可保存版本、保留草稿或放弃草稿；活动运行可停止后关闭，或明确交给后台继续。不能将关闭 UI 解释为运行成功或已取消。

## 视觉系统

| 项目 | 要求 |
|---|---|
| 主题 | 明暗与跟随系统，语义色同时有图标/文字 |
| 字体 | 中文系统字体回退，正文 14px 起，源码使用等宽字体 |
| 密度 | 标准与宽松两档；间距以 4/8/12/16/24px 为基础 |
| 布局 | 侧栏、属性和底部面板可折叠；窄窗口改为抽屉 |
| 反馈 | 字段错误贴近输入；保存、运行、录制状态分别表达 |
| 动效 | 遵循减少动态效果；状态和停止反馈不等待装饰动画 |

初始有效视口目标为 800×600 CSS 像素。保存窗口位置时核对当前显示器，屏幕拔出后把必要控件恢复到可见区域。

## 键盘、输入法与辅助技术

局部编辑命令、工作台命令和系统热键分层处理。按键配置、注册结果和按钮提示来自同一有效配置；注册失败保留旧配置。

中文组合输入的更新、候选确认、取消和文本提交分开处理。候选确认的 Enter 不触发运行或保存；输入框与 Monaco 获焦时不触发画布删除。

模态层打开时设置合理焦点，关闭后回到仍存在的触发点；迟到提示不能抢走另一个窗口的输入。读屏需要覆盖画布选择、属性编辑、系统文件对话框、保存错误及返回过程。

以 Windows Narrator/NVDA、macOS VoiceOver 和 Linux Orca 的选定组合完成主要任务；自动可访问树检查与实际读屏分别记录结果。WCAG AA 对比度作为视觉目标，图编辑同时提供步骤列表等价入口。

## 原型与图文索引

各页面、弹窗、抽屉、浮条和覆盖层的图与跳转关系见[全界面原型](prototypes.md)。保存失败提供源码原文文本副本和最后有效结构的独立保存入口；只读模式关闭编辑与运行入口。

## 模板、观察与运行配置

资产库提供批量提取入口：来源与参数、检测进度、候选网格、候选详情、命名预览、冲突处理、保存批次和导出。选集数量与可提交状态始终可见，候选取消选择不修改源图。OCR 不可用时提供规则命名或返回设置。

观察中心分会话与记录。会话显示当前目标、周期、变化检测、在途请求和停止过程；记录按时间、状态与会话筛选，详情展示实际截图、结果、用量及保存状态。跳过、失败、取消与保存失败分别呈现。

动作属性为匹配范围与尺度、点击按住时长、组合键和有界循环提供专用控件。参数抽屉分别管理局部与运行共享变量；运行中的变量查看保持只读，并发写入冲突提供重新读取入口。

从节点运行先填写前置值、选择目标并执行检查，再确认创建新运行；缺值、过期计划或目标变化返回具体字段。接管策略明确用于新运行，停止和急停保持可用。

MCP 设置提供传输、监听状态、TLS、来源、客户端令牌、能力目录与预设任务预览。令牌创建只显示一次，撤销页明确关联会话和运行的处置。模型高级配置提供消息结构预览及字段错误，错误不通过全局提示代替。

## 控制关系与入口编辑

节点操作菜单提供“连接出口、设为入口、断开出口、删除节点”。连接面板分别选择来源节点、已命名出口及目标节点，目标列表支持名称搜索。已有连接的替换需要勾选所显示的原连接；未确认时保留候选编辑，不改变流程。断开出口显示其结束或失败传播含义。应用以打开面板时的 editVersion 比较，版本变化时保留选项并重新检查。

连接、替换、断开和入口变更均先计算完整候选图。图环、缺失节点和动作不支持的出口阻止应用；不可达节点逐项列出，可保留为草稿，但运行入口保持不可用，直到连接、删除或重新设置入口。设为入口不自动重连其他节点。一次应用生成一个撤销事务；撤销恢复入口、全部受影响出口及原选择。步骤的上移、下移仅修改布局顺序，按钮同时显示“执行关系不变”；改变执行次序必须编辑出口。

## 复合表达式制作

表达式编辑器提供结构树和 JSON 两种表示，共享同一个 Value AST。每个操作数可选择字面量、数据路径或嵌套运算；运算列表显示参数个数和结果类型，二元运算通过嵌套组合，coalesce 支持 2～8 个操作数。结构树可增删嵌套、替换运算并调整允许变长的操作数顺序。数据选择器覆盖输入、局部变量、运行共享变量、上一步、调用及运行时数据；敏感值不进入预览。

预览将单独的合成输入快照提交给 expression.preview，显示实际结果或缺失路径、除零、类型不匹配的具体位置，不读取桌面或发起外部请求。布尔条件字段拒绝非布尔结果。编辑器保留非法原文及最后有效 AST；切换表示不能丢弃非法编辑，须先修复或明确放弃本次表达式编辑。只有校验通过才写回所选字段，取消保留原字段。错误导航回对应操作数，关闭后焦点返回表达式按钮。

## 轨迹与选区操作

时间轴提供开始和结束数值、选中事件及多问题列表；裁剪与修复先预览，再一次性应用，详见[屏幕与轨迹设计](perception.md)。截图覆盖层提供可聚焦选区、键盘移动和缩放、坐标数值表单；返回原触发页面时仅更新选区，不丢失其他表单值。控件与读屏动作见[无障碍设计](../../ACCESSIBILITY.md)。
