# 验证与验收设计

## 检查层次

| 层次 | 检查对象 | 结果范围 |
|---|---|---|
| 文档检查 | 导航、链接、需求、Schema 和样例 | 文档与契约一致性 |
| 模型单元 | 文档事务、表达式、图、变量、调用 | 纯逻辑输入输出 |
| 契约测试 | TS、Rust、Python 对同一负载的接受和拒绝 | 编码、数值、错误与版本兼容 |
| Engine 集成 | 存储、调度、取消、恢复 | 临时工作空间和替身桌面行为 |
| 原生集成 | Agent、焦点、录制、坐标、权限 | Windows、macOS、X11 及具体 Wayland 会话的实际系统行为 |
| 工作台端到端 | 真实 WebView2/WKWebView/WebKitGTK、文件选择、输入法、读屏 | 安装版用户流程 |
| 发行验收 | 干净机安装、签名、更新和数据恢复 | 具体制品与支持平台 |

文档与契约的检查范围和入口见[文档检查](document-validation.md)。运行代码开始实现后，按组件分别接入 Vitest、Rust 测试、Python 测试与桌面 WebDriver。

## 合同样例

正确组包含零值、false、空串、中文文本、有限运算和允许扩展。拒绝组包含未知动作、坏类型、重复节点、缺失出口、普通图环、错资源类型和越权对象。

同一意图重发与同参数新意图分别测试；错误去重不能吞掉合法新操作。旧请求失败与新请求在途交错时，未确认效果不能被覆盖为未发送。

轨迹对照每个事件的种类、值、顺序和时间，以及累计位移、首事件等待、暂停时间和最终按键集合。完整点列检查与目标画布绘制检查分别执行；总位移、总耗时和终点相同不能代替路径一致。

## 连续绘图专项

Q50～Q53 使用[连续指针设计](../design/pointer-motion.md)中的六种轨迹样例。录制、序列化、导入导出和未编辑区按完整点列核对；原生集成在独立绘图窗口记录实际接收的有序位置、按钮状态及时间，并由收到的事件画图。不可将生成器输出或待发送数组直接当成目标结果。

Windows 全局物理位置验收在虚拟桌面尺寸不超过 16384×16384 的矩阵内，跨平台屏内位置按实际显示区域分别比较；连续 Fréchet 距离不超过 2 个对应显示屏像素，笔画数、闭合关系、转折、交叉顺序相同；回放进行到中段时已出现对应笔画。分别启用和关闭普通指针运动录制，按钮按住区间均完整。相对输入比较目标实际收到的顺序和增量，不以零净位移推定无运动。

分别将源圆环改成只有首尾、将中间位置全部替换成终点、提前释放按钮、一次性追发全部输入和在抬笔间补线，确认验收会失败。屏幕点列、系统发送、目标收到及实际画图分别判定；浏览器目标读取合并事件中的实际点。暂停后的新手势与原笔画分开，不要求释放后仍保持同一笔。

采集和回放的初始负载分别为 125/500/1000Hz、每档 30 秒；达到队列、事件、资源或调度预算时检查具体中断/暂停及清理结果。应用实现后执行这些原生场景。

## 故障注入

在内容写入、文件发布、事务提交、通知发送、输入段接收、原生调用和收据返回各阶段中断。分别检查原数据、新数据、孤立对象、未确认效果及恢复入口。

权限测试包括假管道、同用户无关客户端、伪 session、越工作空间资源、旧能力、外域帧和失效目标。构建测试使用合成密钥标记，检查外部 PR 无发行秘密。

真实输入测试使用独立测试桌面和目标应用，目标应用记录收到的事件与文本。不得在个人办公窗口或真实业务账户上运行破坏性样例。

| 每秒 150 条事件持续 10 分钟 | 编辑可用、积压有界、不丢关键终态 |

## 共享服务专项

Q59 使用一个临时工作空间、两个独立且授权范围明确的客户端及一个 Agent。固定业务输入与对象版本，比较 Studio、MCP 工具/资源和 CLI 的结果；客户端专属游标、随机身份及连接时间分别核对合法性，不混作同一对象。

| 场景 | 检查结果 |
|---|---|
| 处理器与依赖 | 一个方法只有一个 Engine 处理器；UI、Host、Bridge 和 CLI 不直接读写工作空间库或调用原生输入 |
| 编辑预览与执行 | expression.preview 和实际节点使用同一求值器；短路、缺失、false/0/空串、除零、严格类型及限额结果一致 |
| 默认值与查询 | 省略与显式契约默认值等价；工具、资源和界面传入相同筛选，返回相同有权读取的成员与次序 |
| 跨入口保存 | MCP 保存可在工作台读到；工作台未保存草稿保持，旧 baseRevision 保存发生同一冲突 |
| 跨入口运行控制 | MCP 创建运行、工作台按对象权限暂停、MCP 读取同一 runId/controlVersion；失权操作被拒绝 |
| 请求恢复 | 预先提供请求元数据、首次回复丢失及 Bridge 重启后找回原请求；同 ID 换方法/参数拒绝，不同客户端同 ID 互不读取 |
| 权限差异 | 本地编辑/管理方法不对 MCP 发布；公开字段不能注入本地确认；Bridge 身份不替代客户端授权 |
| 取消与资源 | 任一入口发出的取消进入原作业收尾；撤权、查询到期、断线和最后窗口关闭不产生第二份状态 |
| 平台与连续输入 | 相同动作和轨迹分别从工作台与 MCP 启动；共享租约、坐标变换、逐点调度、急停及目标实际路径检查 |

共享服务验收运行 Engine 与入口适配器，原生输入场景在对应平台执行。
