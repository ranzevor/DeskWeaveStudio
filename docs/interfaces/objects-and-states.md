# 协议对象与状态

## 对象

| 名称 | 含义 |
|---|---|
| 工作空间 Workspace | 一组流程、资产、草稿和运行记录的存储边界 |
| 流程 Workflow | 有显式入口、节点、参数和依赖的执行定义 |
| 版本 Revision | 不可变的流程或资产内容身份 |
| 草稿 Draft | 尚在编辑的有效文档与源码原文 |
| 运行 Run | 用固定版本、参数与目标绑定发起的一次执行 |
| 节点 Node | 一个动作或流程控制点 |
| 调用 Frame | 一个流程或子流程的局部变量与执行位置 |
| 资产 Asset | 模板、轨迹、截图或结构化大结果 |
| 目标 Target | 用户选定的窗口、屏幕或区域及其当前系统身份 |
| 输入段 Input Segment | 不能被其他调用穿插的一组输入，如一次拖拽或一段轨迹 |
| 桌面租约 Desktop Lease | 原生代理授予某个运行的临时桌面控制权 |
| 暂停检查点 Pause Checkpoint | 同一存活 Agent 在确定事件边界保留的下一事件、剩余等待和输入状态；失去该实例后不用于续跑 |
| 恢复计划 Resume Plan | 将暂停事实、目标状态和需恢复输入固定到一次本地确认的短期对象 |
| 断点配置 Breakpoint Profile | 绑定固定流程版本并按版本更新的节点断点集合；运行保存其启动时副本 |
| 导入映射 Import Mapping | 便携包源对象到工作空间正式对象与内容版本的对应 |
| 设置覆盖 Override | 当前作用域显式保存的设置值；重置删除该层覆盖并恢复继承 |
| 更新可信根 Update Root | 安装程序固定并通过阈值签名演进的发行公钥和通道委派 |
| 作业 Operation | 已准入的异步处理，保留原方法、所有者、状态和最终结果 |
| 观察检查 Check | 周期到达后的一次核定，可能采集、调用模型或因忙碌跳过 |
| 查询快照 Query Snapshot | 固定筛选成员、次序和内容引用的分页查询对象 |
| 外部效果 Effect | 目标应用实际接受的变化，例如文字被输入或按钮被提交 |

## 三组互相独立的状态

文档状态：`clean`、`dirty`、`saving`、`save_failed`、`conflicted`。无效源码仍是草稿内容，不覆盖最后有效结构。

运行状态：`queued`、`preparing`、`running`、`pausing`、`paused`、`stopping`、`succeeded`、`failed`、`cancelled`、`interrupted`。

输入效果状态：`not_sent`、`in_flight`、`sent`、`verified`、`rejected`、`uncertain`。`sent` 表示系统接口接受输入，`verified` 表示配置的后置检查通过。传输超时本身不决定效果状态。

终态为 succeeded、failed、cancelled、interrupted。终态不能回到运行；重试创建新运行并关联原记录。输入清理失败时运行进入 failed，原生代理拒绝新的输入租约。

## 作业与观察状态

作业状态为 `queued`、`running`、`cancelling`、`succeeded`、`failed`、`cancelled`、`uncertain`。`accepted` 是准入回执；最终结果由 `operation.get` 查询，按原方法解释。`uncertain` 保留原身份查询核定，不自动重发外部请求。

观察会话的活动状态、每次检查结果与记录持久化分别保存。忙碌跳过没有实际采集；无变化跳过包含本次真实帧、基线和差异。`checkedAt` 用于查询排序，`capturedAt` 只在实际采集时赋值。`persistenceFailed` 不能混入正式已保存记录。会话的 `detached` 决定所有者退出后是否继续，授权撤销对两种模式均生效。

查询快照默认 5 分钟到期，翻页不续期；过期后重新查询。已准入导出持有独立引用，继续处理其固定成员。

## 时间和身份

- 持久时间为 UTC，界面按用户时区显示；轨迹时间和运行耗时采用单调时钟。
- 字段名后缀 `Ms` 表示毫秒；轨迹微秒字段以 `Us` 结尾。API 中不混用秒和毫秒。
- 传输序号与超过 JavaScript 安全整数范围的计数使用十进制字符串。
- 程序版本、协议版本、流程格式版本、数据库版本和模型连接版本分别管理。
- 技术标识用于连接对象；界面使用流程名、节点名、目标名称和发生时间帮助用户定位。

## 查询与编辑术语

- 变量快照：同一运行、调用与范围在一个时点的固定投影，后续翻页不混入新值。
- 编辑计划：固定来源内容、目标方式与期限的提交依据；资产保存结果由提交作业的终态确定。
- 内容引用：带长度与摘要的短时不可变内容身份，用于分块传输后的正式提交。
