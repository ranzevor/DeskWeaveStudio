# Studio 前端结构

## 技术组合

| 范围 | 选择 | 职责 |
|---|---|---|
| 宿主 | Tauri 2.12 | 原生窗口、受控命令、文件选择和资源通道 |
| 视图 | React 19.3、TypeScript | 工作台与交互组件，严格类型 |
| 构建 | Vite、pnpm | 静态资源、开发服务、依赖锁 |
| 画布 | React Flow | 节点与连线投影、选择和视口 |
| 源码 | Monaco | JSON 编辑、定位和诊断 |
| 组件 | Radix 可访问原语、shadcn 组件源码 | 菜单、对话框、表单与主题 |
| 样式 | CSS 设计变量、Tailwind | 语义主题、密度与响应布局 |
| 编辑状态 | Zustand | 订阅粒度明确的编辑会话与视图状态 |
| 服务状态 | TanStack Query | 元数据查询、缓存失效与可取消读取 |
| 长列表 | TanStack Virtual | 步骤、事件和大资产列表 |

这些组件按职责组合。首个可构建组合固定具体版本和许可，重点验证 React、Monaco worker、Tauri CSP、画布键盘与读屏行为。画布内部状态不成为流程定义的权威来源。

## 模块与依赖

```text
studio/
  app/              窗口、路由、工作空间与命令菜单
  features/
    workflows/      文档、三视图、属性和版本
    recording/      浮条、时间轴和裁剪
    assets/         模板、轨迹、引用和导入
    templates/      候选提取、命名预览和批次
    observations/   会话、记录、查询和导出
    runs/           运行树、调试与附件
    settings/       显示、热键、连接和容量
  domain/           类型、编辑事务、选择器和纯投影
  services/         Engine 客户端、事件恢复与资源句柄
  components/       工作台公共交互
  workers/          解析、校验和布局计算
```

页面调用功能服务，服务通过有限接口访问宿主。领域模块不导入窗口、系统文件或模型 SDK。共享 UI 包保持纯交互，不能直接启动运行或发送输入。

services 使用 packages/service-client 中从服务契约生成的方法和类型；Host 仅桥接到当前工作空间的 Engine。业务有效性、保存、查询、版本冲突和运行状态由[共享应用服务](../architecture/shared-services.md)决定。前端保留编辑事务及结构性即时反馈，不实现第二套流程执行、表达式求值或权限规则。

## 状态划分

| 状态 | 保存位置与更新规则 |
|---|---|
| 源码原文与最后有效模型 | DocumentSession；按 editVersion 提交编辑事务 |
| 编辑草稿 | Engine 的 draft.write/read/discard；原文与最后有效模型同事务 CAS，回执确认持久化代次 |
| 不可变版本 | Engine 的 workflow.save；只有有效定义可以提交 |
| 画布、步骤和源码投影 | 从同一有效模型派生，不各自保存独立动作参数 |
| 选中项、展开与面板 | 会话状态；不进入流程业务撤销历史 |
| 布局、缩放与窗口偏好 | editor_layout 和用户设置；不改变执行 |
| 运行与调用树 | Engine 快照加有序事件的只读投影 |
| 查询缓存 | 按工作空间、对象和版本分键；撤权或退出时清除 |
| 帧和大图 | 资源句柄与有界缓存；视图关闭后释放 |

输入法组合期间保留原文，不在每次组合更新后替换整个源码缓冲。解析结果只在文档身份与 editVersion 仍匹配时应用。旧校验、旧保存与旧模型观察不能覆盖新状态。草稿正文、模型代次、私有内容引用及丢弃墓碑按[本机草稿协议](../interfaces/local-protocol.md#编辑草稿的持久化)处理；非法原文不调用正式版本保存。

## 编辑事务

用户操作转换为语义命令，例如添加节点、改参数、连接出口和替换资源。一个命令产生可撤销补丁、选择修正及诊断失效范围。拖拽移动节点、批量粘贴和删除分别合并成合理的一次操作。

删除节点先计算相关入边、出口与引用，提供准确影响；保留仍被其他节点引用的资源。复制粘贴重新分配节点身份，保留内部关系，对外部引用显式处理。跨工作空间粘贴需先导入依赖，不能保留另一个工作空间的授权令牌。

源码修改通过解析与结构校验后生成同一模型事务；非法原文保留，画布展示最后有效内容和对应问题入口。运行使用已封存版本，运行光标与当前编辑光标分别绘制。

## 属性面板与动作结果

基础字段根据动作 Schema 选择文本、数字、布尔、枚举、资源与表达式控件。位置、轨迹、变量和多选分支使用专用编辑器，写回的仍是同一公共格式。

显示字段单位和合法范围，表达式与字面量有明确切换。动态表达式无法在编辑时确定的参数，在运行求值后校验。错误分别定位源码、节点或字段；节点列表按诊断 nodeId 筛选，无节点归属的问题在流程级列表呈现，流程是否有效仍以完整校验结果和诊断总数判断；技术标识保留在诊断渠道，用户看到动作名、目标、原因与处理入口。

源码与属性导航使用服务返回的完整 fieldPath；按 JSON Pointer 解码后选择原文中的字段，空路径选择文档根。路径显示可使用省略样式，定位、复制和诊断去重使用完整值，不能从显示文本重建路径。AST 诊断定位到具体 Value 或操作数，表达式编辑器从各字段的 Value 根计算深度。

运行控件按服务端状态与当前能力启用。点击启动后等待运行接收回执；暂停和停止请求分别展示过程状态，终态由快照确认。全局急停的原生入口独立于前端状态。

## 渲染与资源

大型步骤、事件和资源列表虚拟化；画布按节点订阅，参数更新不重绘所有节点。布局、JSON 解析和重型校验进入 worker；每个作业绑定文档代次，可取消并丢弃过期结果。

Monaco 按需加载，每份文档复用一个模型，退出时释放；未打开源码的工作空间不创建编辑器实例。图像先显示缩略图，原图分块读取，及时回收位图、对象 URL 与旧帧。

事件处理先检查 epoch 和序号，再批量更新投影；普通进度可合并，终态和错误不丢弃。保存和运行状态取自 Engine 返回的业务结果。

## 组件与视觉变量

色彩、字号、圆角、默认侧栏与属性区尺寸以[视觉系统](visual-system.md)为唯一设计入口。组件使用语义变量，标准编辑器沿用已确认的浅灰白画布、淡蓝点阵和白色节点；显式深色主题使用对应主题值。

面板宽度、折叠与视口作为布局偏好保存，不改变执行文档。窗口缩小、显示器变化或恢复旧布局时重新约束可见区域；小视口优先保留步骤和运行控制，将资产与属性变为抽屉。

颜色按实际文本与背景组合验证对比度。拖拽、悬停和双击均提供键盘或菜单路径；组件实现和原型均从同一视觉变量映射，避免另设不一致的默认值。

## 跨窗口与恢复

主窗口、录制浮条、框选层和资源预览分别取得最小能力。框选层只提交选区结果，浮条只控制当前录制，预览不获得流程执行权限。

命令携带窗口、文档、工作空间和连接代次；回复绑定原接收者。主窗口关闭前分别处理草稿持久化、所属运行、独立观察、作业与监听服务。run 与 observation 的 detached 由创建时固定；查看窗口不成为对象拥有者。恢复打开的文档和布局时不自动恢复桌面输入。

Host 监听 WebView 失效和窗口销毁，撤销原窗口能力并把实际客户端丢失传递到 Engine；UI 活动状态由对应窗口的存活状态与连接代次确定。窗口、后台和进程收尾顺序见[组件生命周期](../architecture/lifecycle.md)。

检查路径由[交互设计](experience.md)、[无障碍要求](../../ACCESSIBILITY.md)和 Q02/Q03/Q11/Q16 组成。实现阶段以真实 WebView2 执行原生对话框、输入法和辅助技术任务。

## 界面原型映射

[原型目录](prototypes.md)将工作空间、编辑器、运行与设置划分到具体画板。中文参数与变量显示别名使用命名空间扩展保存，执行键保持稳定；源码与表达式仍使用公共契约字段。原型与应用组件分开维护。

## 视觉工作会话

模板候选的选择与名称覆盖保存在 ExtractionSession，服务候选版本和命名预览分别保存，不以缩略图数组充当正式资产。提交前确认选集及 proposalHash 仍匹配；重复回执只应用一次。

ObservationSession 的控制状态和 ObservationQuery 的分页快照分开维护。自动轮询只更新会话投影，不能向历史查询列表随意插入新行；筛选或时区变化创建新查询代次。大截图按需读取，切换记录后释放前一张位图。

网络配置、令牌管理和模型凭据仅由相应设置窗口取得本地能力。组件从服务状态决定操作是否可用，不以页面跳转推断服务已经监听、观察已经停止或资产已经提交。

## 专用编辑会话

TopologySession 保存基准 editVersion、候选入口与出口差异、不可达集合及一次撤销补丁；正式输出仍为 Workflow.entry 和 Node.on，不另存执行关系。步骤显示顺序保存为布局偏好。

ExpressionSession 保存原字段、非法原文、最后有效 Value AST、当前结构树路径及合成求值快照。递归节点依照 values.schema.json 构造；预览调用 expression.preview，由 Engine 的运行求值器计算结果并检查类型和限额。计算失败按 details.expressionPath 选择对应操作数，按 details.reason 区分缺失路径、除零、类型与容量错误，message 显示具体原因；请求结构错误按 details.fieldPath 定位参数。异步请求绑定文档与表达式编辑代次；修改值或上下文、取消或切换字段后旧结果失效。

TrajectoryEditSession 保存固定源版本、左闭右开的选段、问题及逐项修复方案、预览输出与撤销补丁。修改选段或任一方案使旧预览失效；应用时再次核对源版本和预览摘要。输出为完整 Trajectory，预览按事件显示时间、动作、位置或按键；相对移动与滚动显示带符号的水平、垂直分量，保持来源数值及单位语义。预览不发送桌面输入。

CaptureSelectionSession 保存捕获帧身份、目标与拓扑代次、targetPixels 矩形、当前手柄及数值草稿。键盘、数值输入与指针共享同一矩形；错误数值保留原文，不能覆盖最后有效矩形。确认时核对帧和目标仍有效；失效后重新采集，保留上一选区供比较，不直接使用旧坐标。

## 版本、变量与提交会话

RevisionQuerySession 和 ConnectionQuerySession 保存服务返回的固定分页；VariableInspectionSession 保存快照、范围、调用帧和dataVersion，过期重查而不拼接新旧值。ConnectionTestSession 固定编辑代次与原作业，修改后取消并丢弃过期投影。AssetEditSession 保存源、目标头、编辑计划、未提交内容和原作业；成功回执匹配当前文档后才绑定新版本。完整事务见[制作设计](authoring-transactions.md)，变量和查询见[运行检查](runtime-inspection.md)。

异步进度与最终刷新同时核对实际活动路由、会话对象和操作代次。离开页面后不改变当前导航；返回同一编辑会话时继续显示原操作的最新状态，重新建立会话后丢弃旧回调。取消、重新测试和编辑代次变化使旧操作回调失效；视图刷新不发起导航或新增历史记录。

## 三个平台的宿主行为

WebView2、WKWebView 和 WebKitGTK 分别验证同一 React 功能，重点覆盖 Monaco worker、CSP、画布手势、输入法、资源 URL、文件拖放和读屏。系统菜单与界面快捷键使用平台主修饰键；流程中的已录制按键保持原值。

目标与录制入口读取 desktop 能力摘要，按具体状态提供授权、重新选择来源或切换会话；系统只提供部分显示屏时按实际选择显示，不标为全部。屏内像素轨迹按 layoutBounds 布局并逐屏投影，layoutBounds 未提供时使用显示屏列表，不能推测排列。平台交互与授权规则见[跨平台架构](../architecture/platforms.md)。
